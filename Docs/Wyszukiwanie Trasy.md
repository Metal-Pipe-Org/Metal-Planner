# Scope
Mechanizm wyszukiwania trasy obejmujący start z pojazdu lub z punktu i punkt docelowy. 
Obejmuje również na chwilę obecną wyświetlanie tego wyszukiwania na mapie oraz w schemacie eksperymentalnym.
Obejmuje wszystkie rodzaje transportu jakie mamy w aplikacji. Między innymi autobusy, tramwaje, pociągi, rowery i trafikary.
